# 🍳 SomCooked

A simple web application where users can create, save, and share cooking recipes.

---

## ✨ Features

- Create your own recipe
- Save recipes privately (visible only to you)
- Publish recipes for others to see
- Browse and read recipes shared by other users
- Clean and user-friendly interface to view ingredients and cooking steps

---

## 🛠 Tech Stack

- **Java**  
- **Spring Boot**  
- **Spring Security** (session-based authentication)  
- **MySQL**
